# Racine

Version 0.1.0

Une fondation CSS pour construire un design system : HTML sémantique stylé sans classes, tokens (couleurs, espacements, typographie) en variables CSS, 5 thèmes (light, dark, paper, forest, ocean) et quelques composants via classes utilitaires (boutons, toggle, tooltip...).

## Utilisation

Inclure `racine.css` dans le `<head>` de votre page HTML5.
